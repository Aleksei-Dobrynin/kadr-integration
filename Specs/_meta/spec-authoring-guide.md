# Контракт формата спецификаций Kadr

> **Когда читать:** Перед созданием/правкой Specs. Родитель: [README](../README.md) · стек: shared.

## Правила

1. **L0 + L1–L3.** L0 — вход и мета; L1 — ядро, архитектура, сквозные контракты/процесс; L2 — слои и паттерны; L3 — модули. Уровень определяется frontmatter, не глубиной каталога. Причина: предсказуемый спуск агента от контекста к конкретной задаче. ✅ README → CORE → layer/pattern → module; ❌ объявлять модуль самостоятельной архитектурой.
2. **Обязательный frontmatter:** `title`, `level`, `type`, `stack`, `parent` (кроме README), `sources`, `status`, `updated`. `related` — список относительных существующих `.md`-путей. `parent` разрешается относительно документа и образует ациклическую цепочку до README. Стек: `desktop`, `renderer`, `main`, `shared`, `python`; тип: `index`, `meta`, `process`, `architecture`, `layer`, `pattern`, `module`. ✅ draft; ❌ самовольно stable/frozen.
3. **Структура:** один H1; «Когда читать» и родитель; `## Правила`; `## Переиспользуемое`; `## Эталонные реализации`; `## Текущее состояние / долг`; `## Open Questions`; `## Навигация`. Причина: читатель различает норму, реализацию и нерешённое. Неприменимые средние разделы допустимо опускать; правила и навигация обязательны. Мета/индекс/процесс могут использовать специализированные разделы с обязательной навигацией.
4. **Каждая норма:** правило → почему → ✅/❌ → проверенный репо-относительный `file:line`. Несколько норм допускаются таблицей `Правило | Почему | ✅ / ❌ | Эталон`. Причина: воспроизводимое применение и проверяемые доказательства. ✅ реальная строка функции; ❌ выдуманный символ/номер из отчёта.
5. **Факт ≠ новое решение.** Записывать унаследованные инварианты по коду/исходной карте, но обозначать ограничения в долге. Рекомендации (CI, Python pins, security hardening) не становятся нормой до выбора оператора. ✅ «не проверено на Windows»; ❌ «гарантированно работает» без запуска.
6. **Одно место владения нормой.** Слой фиксирует границы; паттерн — сквозной инвариант; модуль ссылается на них и добавляет своё. AGENTS и память — роутеры. Причина: устранение дрейфа. ✅ относительная ссылка; ❌ три полных копии одного правила.
7. **Имена:** UPPER_SNAKE_CASE для предметных документов, lower-case `_meta/*.md`, папки lower-case. `templates/` — вне нормативного графа; `_archive/` — история, не активные нормы. ✅ смысловой split; ❌ файлы `PART_2`.
8. **Кодовые ссылки:** repo-relative путь и строка существующего файла. Для генерируемого `~/kadr-fragments` ссылаться на шаблон/генератор в `electron/fragment-kit/` или `electron/fragments.ts`, а не на несуществующий в репо `src/_kadr/`. Причина: ссылки должны проверяться с диска.
9. **Бюджет документа:** ориентир ≤220 строк; превышение — повод разделить concern, не обрезать доказательства. Изменение кода и обновление затронутых anchors — одна работа. Проверка: `node tools/check-specs.mjs`.

## Источники контракта
